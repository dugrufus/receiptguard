# Message Hub Spec

## Thread Model
- Per-case timeline: Status changes, System events, User messages, Merchant replies.

## Timestamps
- Local timezone (e.g., 2:14 PM MST); absolute date on day boundary.

## SLA Hints
- 'Typical reply: 3–5 business days' based on merchant profile.

## Quick Replies
- 'Thank you', 'Here’s my order #…', 'Attaching the requested photo…'.

## Status Legend
- Waiting, Replied, Resolved; color-coded; filters by status.
